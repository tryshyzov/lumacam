**Русский**

Исправлено:
- **Windows:** после обновления изнутри программы LumaLink Studio иногда не запускалась сама и показывала ошибку «Failed to load Python DLL». Теперь после обновления она открывается сама.
  Если вы уже видели эту ошибку после обновления до 0.5.2, просто закройте окно и запустите программу — 0.5.2 установлена правильно. Обновление до этой версии уже пройдёт без ошибки.

**English**

Fixed:
- **Windows:** after updating from inside the program, LumaLink Studio sometimes failed to start by itself and showed «Failed to load Python DLL». It now opens by itself after an update.
  If you saw this error after updating to 0.5.2, just close the window and start the program — 0.5.2 is installed correctly. Updating to this version will no longer show the error.
